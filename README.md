# Password Generator

A beautiful console password generator built with C#.

## Features
- Password length: 6-32 characters
- Character types: digits, lowercase, uppercase, special symbols
- Strength check: Weak/Medium/Strong
- Clean UI with Spectre.Console

## Built With
-C# / .NET 8
-Spectre.Console
-TextCopy
